# Nihongo — 每日日本語

纯静态日语学习 App，不依赖 Lovable。

## 当前课程
- `?date=2026-10-19` — 《新版中日交流标准日本语 初级》第1课
- `?date=2026-10-20` — 第2课《これは本です》

## 功能
- 单词、假名、词性、中文释义、语感与例句
- ja-JP 系统语音朗读
- 0.8x / 0.9x / 1.0x
- 已掌握进度（localStorage）
- 听力全文播放 / 隐藏原文 / 中文大意
- 语法详解
- 日期直达链接

## 部署
这是纯静态项目，GitHub Pages 可直接部署仓库根目录，无构建步骤。
